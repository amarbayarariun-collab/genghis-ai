# Sumiro techniques

The files in the reference bundle (`xikhar.github.io/sumiro`, 55 files, three of them byte-identical duplicates) contain no copyright line, SPDX identifier, or license grant. Other repositories by the same author are MIT, but those licenses do not cover this bundle. Nothing from the bundle is copied into this game.

Each system below is written for the Mongolian Secret History camp. Japanese chapter text, temple geometry, sword moves, and the ink G-buffer from the bundle are not used. three.js stays the npm package at 0.170. The Draco meshes are the ones from commit `6432263`, decoded with the local decoder already in `public/draco/`.
