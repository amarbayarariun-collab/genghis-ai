# МСХ · Тэмүжин — Playable Legacy (v2)

Монголын Нууц Товчооноос суралцах Three.js тоглоом (олон бүлэг + Mixamo Тэмүжин, морь унах, үсрэх, дуу); `index.html` нь бүх кодоо дотроо агуулсан нэг файл тул сервер шаардлагагүй.
Статикаар ажиллуулах: энэ хавтаст `python3 -m http.server 8000` ажиллуулаад `http://127.0.0.1:8000/` хаягийг нээнэ (эсвэл `index.html`-ийг шууд нээж болно).
Эх кодоос ажиллуулах: `../msh-game-src/` хавтаст `npm install && npm run dev` (standalone build: `npm run build:standalone`).
